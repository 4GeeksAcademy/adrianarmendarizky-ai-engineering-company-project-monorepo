# Brasaland Digital — Backend API (`services/api/`)

This folder currently hosts two independently built FastAPI features for
Brasaland Digital. **They have not been merged into a single app yet** — each
has its own entry point, its own dependency setup, and its own docs below.

| Feature | Entry point | Default port |
|---|---|---|
| Incidents (after-sales analysis) | `app.main:app` | 8000 |
| Supplier Directory | `main:app` | 8000 |

> **Running both at once:** since they share a default port, start one of
> them with `--port 8001` (or similar) if you need both running
> simultaneously — e.g. `uvicorn main:app --reload --port 8001` for Supplier
> Directory while Incidents holds 8000.

---

## Incidents API

FastAPI backend for the after-sales incident analysis feature (Milestone:
Incident File Analysis).

It reuses the exact same validation and metrics logic as `scripts/analyze.py`
— see `app/incidents/controller.py` for how it imports that module directly
instead of duplicating any of its rules.

### Endpoints

- `POST /api/incidents/analyze` — multipart/form-data upload, field name
  `file`. Returns the same summary the script prints, as JSON. Returns `400`
  if the file is empty or can't be read as CSV data.
- `GET /api/incidents/results/export` — returns the most recent analysis as a
  downloadable `results.csv`. Returns `404` if nothing has been analyzed yet
  in this server session.

### Running it locally

From inside `services/api/`:

```bash
python -m venv venv
source venv/bin/activate        # on Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

The API will be available at `http://localhost:8000`. Interactive docs
(auto-generated by FastAPI) are at `http://localhost:8000/docs` — useful for
testing the upload endpoint without the frontend.

### Running in GitHub Codespaces

The API itself doesn't need any change to run — but if the `uis/incidents`
frontend is accessed via a forwarded Codespaces URL
(`https://...app.github.dev`) rather than `localhost:3000`, the browser will
send that URL as its request origin. `app/main.py` already allows any
`*.app.github.dev` origin via a regex, so no CORS changes should be needed —
just make sure port 8000 is forwarded (check the Ports tab) and set to at
least the visibility your frontend needs to reach it.

### Notes

- No database yet: the last analysis is kept in memory (a Python variable)
  and resets if the server restarts. That's intentional for this milestone —
  same as the in-memory task list in the voice command API project.

## Supplier Directory API

Replaces Procurement Manager Lucía Fernández's shared spreadsheet with a
single source of truth for supplier data: a FastAPI + TinyDB + Pydantic
backend, paired with a page in the internal Back Office app
(`uis/backoffice/app/suppliers/`).

### Business rules enforced

- Currency must match country: Colombia → COP, USA → USD (rejected otherwise)
- `categories` must have at least one value, from a fixed set of 8
- `rate_per_unit` must be greater than 0
- Suppliers are suspended, not deleted, in normal operation — `DELETE`
  exists only to correct bad data entry
- Every rate change stamps `updated_at`, for Procurement's price audits

### Endpoints

| Method | Path | Description |
|---|---|---|
| POST | `/suppliers` | Create a supplier, returns the full object with ID |
| GET | `/suppliers` | List all suppliers |
| GET | `/suppliers?country=X` | Filter by country (`Colombia` / `USA`) |
| GET | `/suppliers?category=Y` | Filter by category |
| GET | `/suppliers/{id}` | Get one supplier (404 if not found) |
| PATCH | `/suppliers/{id}/rate` | Update the rate, stamps `updated_at` |
| PATCH | `/suppliers/{id}/status` | Activate/suspend (422 on invalid value) |
| DELETE | `/suppliers/{id}` | Remove a record (404 if not found) |

Interactive docs at `/docs` once the server is running.

### Running it locally

From inside `services/api/`. This app currently manages its own dependencies
separately from `requirements.txt` above (unifying the two is a reasonable
follow-up once both features live under one entry point):

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install fastapi "uvicorn[standard]" tinydb pydantic

python seed.py          # loads the 15 suppliers from CONTEXT-brasaland.md
                         # safe to re-run — skips itself if data already exists

uvicorn main:app --reload --port 8000
```

The API also seeds itself automatically on startup if the database is empty,
so `uvicorn main:app` alone is enough for a fresh clone.

### Running in GitHub Codespaces

If the `uis/backoffice` frontend is accessed via a forwarded Codespaces URL
rather than `localhost:3000`, two things need to point at the forwarded URL
instead of `localhost`:

1. `NEXT_PUBLIC_API_URL` in `uis/backoffice/.env.local` — use the forwarded
   port-8000 URL from the Ports panel
2. Port 8000's visibility — set it to **Public**. A Private port blocks
   browser `fetch` calls behind a GitHub auth wall, which surfaces in the
   browser as a CORS error even though the real cause is port visibility.

### Manual test commands

```bash
curl http://localhost:8000/suppliers
curl "http://localhost:8000/suppliers?country=USA"
curl "http://localhost:8000/suppliers?category=carne"
curl -i http://localhost:8000/suppliers/999          # expect 404

curl -X POST http://localhost:8000/suppliers \
  -H "Content-Type: application/json" \
  -d '{"name":"Test Co","country":"USA","categories":["bebidas"],"rate_per_unit":5.0,"currency":"USD","status":"active"}'
```

## Project structure

```
services/api/
  app/
    main.py                 Incidents FastAPI app (uvicorn app.main:app)
    incidents/
      controller.py           Imports scripts/analyze.py directly — no duplicated logic
      routes.py                POST /api/incidents/analyze, GET /api/incidents/results/export
  requirements.txt          Incidents API dependencies

  main.py                  Supplier Directory FastAPI app (uvicorn main:app)
  models.py                 Pydantic models + business-rule validators
  database.py                TinyDB connection + suppliers table
  seed.py                     Loads the 15 suppliers from CONTEXT-brasaland.md
  routes/
    suppliers.py               All 7 supplier endpoints
  db.json                   TinyDB data file (generated, gitignored)
```
